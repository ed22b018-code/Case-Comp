# MAI Explorer — Architecture & Data Contract

Sun Pharma / Trilytics case competition. Milestone 1: interactive front-end. Milestone 2: full scoring pipeline under `/pipeline/`. Milestone 3: decision-support views + static export. App reads `data/scores.json` + `data/clusters.json` (M2/M3 pipeline output).

## Tech Stack

React 18 + Vite 5 + TypeScript, react-leaflet 4 (choropleth — **pure SVG, no tile layer**), Recharts 2 (charts), Tailwind 3, html-to-image (export). No backend — all data is static JSON loaded from `/data/`.

## GeoJSON Join Keys

| Property | Description |
|----------|-------------|
| `district` | District name (primary display label) |
| `st_nm` | State name |
| `dt_code` | District code (join key; missing on 35/759 features) |

Join logic: `dt_code` if present, else `district__st_nm` fallback. ~34 features have no district name (state-level ghost features) — rendered grey, no scores.

## Data Contract — `scores.json` (M2/M3)

Generated by `python pipeline/run_pipeline.py`. Default scoring: **geometric** (HDI-2010, M3+).

```typescript
{
  generatedAt:     string,   // ISO timestamp
  scoringFunction: string,   // "geometric" (M3 default) | "arithmetic"
  weights: Record<'overall'|'chronic'|'acute', { demand, monetization, access, growth }>,
  districts: DistrictScore[]
}
```

### DistrictScore

```typescript
{
  districtId:    string,         // dt_code (canonical join key)
  districtName:  string,
  state:         string,
  clusterLabel?: number,         // 0-7 (from k-means, k=8)
  archetype?:    string,         // human-readable cluster name
  joinMethod?:   'dt_code' | 'fallback',
  scores: { overall/chronic/acute: { current: number, future: number } },  // 0-100 headline
  pillars: { overall/chronic/acute: { demand, monetization, access, growth } }  // STANDALONE 0-100
}
```

**Pillar contract (Amendment 1):** Pillar values are standalone 0-100 scores, NOT weighted contributions. Headline = Π(pillar_score ^ weight) under geometric (default). PillarWaterfall shows raw bars on 0-100 axis.

## Data Contract — `clusters.json` (M3)

```typescript
{
  k: number,       // 8
  method: string,  // "kmeans"
  profiles: ClusterProfile[]
}

interface ClusterProfile {
  clusterId:    number,    // 0-7
  archetype:    string,    // e.g. "Premium Urban"
  n_districts:  number,
  demand/monetization/access/growth: number  // 0-100 pillar means
}
```

## Quadrant Thresholds (M3)

Quadrant assignment is computed **once** in `useData.ts` from national medians:
- X-threshold: `medianCurrent[therapy]` (median of `scores[therapy].current` across all 710 districts)
- Y-threshold: `medianGrowth[therapy]` (median of `future − current` across all 710 districts)
- Stars (X≥med, Y≥med), Cash Cows (X≥med, Y<med), Emerging (X<med, Y≥med), Low Priority (X<med, Y<med)
- Stored in `district.quadrant[therapy]`; reused by Matrix and Simulator — never recomputed per view.

## Color Scales

- **Sequential** (current / future): YlOrRd `#FFFFD4` → `#993404`
- **Diverging** (growth Δ): `#D73027` (red) → `#1A9850` (green), centred at 0
- **Archetype** (cluster): 8-color categorical in `colorScale.ts:CLUSTER_COLORS`

## Export Capability (M3)

| Export | Format | Where |
|--------|--------|-------|
| Map (score or archetype) | PNG (2× DPI) + SVG | Map pane top-right buttons |
| Opportunity Matrix | PNG + SVG (native Recharts SVG) | Matrix pane top-right buttons |
| Deployment Simulator shortlist | CSV | Simulator export button |
| Rankings table | CSV | Rankings export button |

**Map SVG note:** The map uses a pure-SVG GeoJSON layer (no raster tiles). SVG export extracts the Leaflet overlay pane `<svg>` element. PNG is captured via html-to-image at 2× pixel ratio.

## Deployment Simulator Strategies

| Strategy | Scoring | Pool |
|----------|---------|------|
| Maximize Current | `current` | All filtered districts |
| Maximize Future | `future` | All filtered districts |
| Balanced | `(1−w)×current + w×future` | All filtered; `w` from slider (0=harvest→1=invest) |
| Emerging Bets | `future − current` | Districts **below** median current score only |

## State Management (M3)

All UI state in `App.tsx`:
- `therapy: Therapy`, `view: ViewMode` — global filters
- `activePane: Pane` — which main view is shown
- `colorMode: ColorMode` — Score or Archetype (map only)
- `selectedDistrictId: string | null` — shared DistrictPanel across all panes

## Milestone 2 — Pipeline Architecture

### Adding a real indicator

1. Drop a CSV at `pipeline/raw/<indicator_id>/<indicator_id>_2021.csv` with columns `[district_id, value, year]`.
2. Add an entry to `pipeline/config/index_config.yaml` under `indicators:` with `status: READY`.
3. Re-run `python pipeline/run_pipeline.py` — the ingestion layer picks it up automatically.

### Changing final weights

Edit `pipeline/config/index_config.yaml` → `weights:` block. Re-run pipeline. Commit config + regenerated `data/scores.json`.

### Switching aggregation

`scoring_function: geometric` is the M3 default (HDI-2010 non-compensatory). Set `arithmetic` to revert. Both are always computed and compared in `pipeline/reports/output/aggregation_comparison.md`.

### Activating real validation

Place IPM/IQVIA district-level pharma sales data at `pipeline/raw/validation/validation_proxy.csv` with columns `[district_id, sales_value]`. Harness activates automatically on next run.

### Running tests

```bash
cd pipeline && pytest tests/ -v
# 39 tests across 7 modules, all passing
```
